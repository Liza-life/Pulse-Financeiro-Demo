# PULSE Financeiro

## A Inteligência Financeira que Age com Você

O PULSE Financeiro é uma plataforma de inteligência financeira pessoal criada para transformar dados financeiros em decisões inteligentes.

Mais do que controlar entradas e saídas, o PULSE analisa, interpreta, alerta e auxilia o usuário através de uma IA financeira integrada.

---

## Principais recursos

- Dashboard financeiro em tempo real
- PULSE IA Financeira
- Assistente por voz
- PULSE Score de 0 a 1000
- Calendário financeiro inteligente
- Central de alertas
- Controle de cartões de crédito
- Controle de parcelamentos
- Metas financeiras
- Investimentos
- Modo Família
- Relatórios inteligentes
